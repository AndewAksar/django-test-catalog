# Django Test Catalog

## Запуск через Docker
1. Соберите и поднимите сервисы (PostgreSQL 13, Redis 5 и Django) командой:
   ```bash
   docker compose up --build
   ```
   В контейнере автоматически выполнятся миграции и запустится сервер разработки на `http://localhost:8000`.

2. При необходимости измените параметры окружения (пароль БД, хосты и т.д.) в `docker-compose.yml`. Все они пробрасываются в `settings/local.py` через переменные среды. При первом запуске `docker-compose` скопирует шаблон `settings/local.py.example` в `settings/local.py`, чтобы не хранить чувствительные данные в репозитории. Убедитесь, что файл называется точно `settings/local.py.example` (без лишних расширений), иначе контейнер выводит ошибку и завершает старт.

3. Для ручного выполнения команд (например, создание суперпользователя) используйте:
   ```bash
   docker-compose run --rm web python manage.py createsuperuser
   ```

## Локальная настройка без Docker
Если вы запускаете проект без контейнеров, создайте файл `settings/local.py` (шаблон уже включён и использует переменные среды) и укажите параметры подключения к PostgreSQL/Redis, `DEBUG`, `ALLOWED_HOSTS` и т.п. Пример переменных приведён в `docker-compose.yml`.
